## 📖 About The Project

**Krishna Harmony** is a real estate landing page built for a luxury villa community by **Real Assets**, located on Waghodia Road, Vadodara. The site presents the property's architecture, amenities, specifications, and location through a cinematic, scroll-driven experience powered by **GSAP animations** — smooth reveals, parallax imagery, and animated counters that bring the property to life as visitors scroll.

Beyond the visual polish, the site is built as a genuine lead-generation landing page: a project gallery, detailed amenity breakdown, construction specifications, an interactive location section, and a direct contact/site-visit form.

> 💬 *"An iconic oasis of harmony, away from the city's chaos."*

## 🚀 Getting Started

### Option 1 — Use the live version

No setup needed 👉 **[Open Krishna Harmony](https://shahrishabh1513-jsk.github.io/krishna-harmony-gsap-animated-website/)**

### Option 2 — Run it locally

```bash
# 1️⃣ Clone the repository
git clone https://github.com/shahrishabh1513-jsk/krishna-harmony-gsap-animated-website.git

# 2️⃣ Navigate into the project directory
cd krishna-harmony-gsap-animated-website

# 3️⃣ Open index.html in your browser
#    (or use the Live Server extension in VS Code)
```

✅ No build tools, dependencies, or installations required — it's a pure **HTML/CSS/JS + GSAP** project.
